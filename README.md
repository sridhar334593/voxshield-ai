# VoxShield AI

Build a premium, modern web application called VoxShield AI – AI Voice Cloning Impersonation Detection System.

This is a Smart India Hackathon (SIH) software prototype under the Blockchain & Cybersecurity theme.

The application should have a professional startup-style UI with:

 Dark cybersecurity theme

 Blue and cyan gradients

 Glassmorphism design

 Modern animations

 Fully responsive layout

Create the following pages only:

 Home

 Hero section

 Animated microphone

 Statistics cards

 Features section

 Call-to-action button

 Voice Scanner

 Drag & Drop audio upload

 Upload WAV and MP3

 Browser microphone recording

 Audio waveform preview

 Audio information card

 Scan button

 Results Page

 Authenticity Score

 Human Probability

 AI Probability

 Confidence Meter

 Risk Meter

 Explainable AI cards

 Download Report button

 Dashboard

 Detection History

 Charts

 Recent Reports

 Analytics Cards

 About Page
Explain AI Voice Cloning, its dangers, and how VoxShield AI works.

 Team Page
Team member cards with roles.

 Contact Page

Use React + Tailwind CSS with a clean component architecture
